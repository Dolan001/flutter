Use the verification skill and write evidence only. Do not repair implementation.
Reject platform drift, missing states, unvalidated network data, insecure storage,
unhandled lifecycle behavior, or unverifiable release claims.
Reject feature/file vocabulary not traceable to the PRD or justified familiar fallbacks, generic
pages/widgets/managers, misplaced layer behavior, and module-size violations.
