# Inspect Flutter target

Inspect manifests, lockfile, analysis options, entrypoints, feature boundaries,
navigation, state ownership, generated code, network and storage adapters, plugins,
localization, assets, tests, flavors, and native Android/iOS configuration. Sample
representative features instead of reading the entire tree. Record detected versions,
brownfield conventions, platform gaps, confidence, and compatibility risks.
