# Create Flutter mobile application

Resolve a supported stable Flutter/Dart toolchain, then generate only declared target
paths. Establish feature-first boundaries, validated environments, navigation, theme,
localization, typed networking, secure storage, lifecycle handling, test foundations,
and Android/iOS identifiers and flavors. Never place secrets or signing material in
source control.

Read `../../rules/project-structure.md` and
`../implement-flutter-vertical-slice/references/production-delivery.md` before choosing
state, navigation, serialization, persistence, plugins, platform permissions, or test
boundaries.
